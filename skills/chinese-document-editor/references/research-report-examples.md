# 虚构研究报告样本

本页练习如何把观察、判断和证据缺口写在一起。样本来自包内 [活动候补案例](workshop-observations.md)，所有机构、数据与记录均为虚构。

## 正文示例

山岬工坊的活动页在满员后只展示“已满”。训练资料中的四条私信里，三条询问如何补位。其中一位访客在店员转达有空位后，仍需要重新确认时间。店员手工维护消息顺序，训练记录中有一次两位店员重复回复同一个名额。观察支持先给访客明确的候补入口，并让店员在后台看到当前队首和剩余名额。[观察记录 E1–E3](workshop-observations.md)

样本也有一位更愿意改报其他场次的访客。候补与改报各处理一种选择。本轮只增加候补，保留已有的查看其他活动入口。样本可以解释流程问题，候补能提高多少补位率仍需生产数据。

## 核对要点

- 写“训练资料中三条私信询问补位”，保留来源和分母。
- 把现有路径、反例与产品取舍放在相邻段落。
- 把预计效果写成待验证的问题，原型通过时记录已验证的场景。
