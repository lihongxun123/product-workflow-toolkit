# 按影响选择原型验收项

这是检查菜单，不是每次全部执行的表格。每项以可观察结果判断；无法执行时说明影响，不虚构通过。

| 改动对象 | 必要检查 |
|---|---|
| 名称、图标、共享入口 | 当前页与共享入口一致，目标正确；图标、文字基线和点击范围符合对应组件契约 |
| 布局与视觉细节 | 对照适用样板检查主次、分组、字级、对齐、留白、边框和控件；查看首屏与正文，覆盖代表性桌面／手机、适用主题及长内容。改版前后保持相同条件，不能仅以无溢出判定通过 |
| 吸顶与滚动 | 展开/收起状态、标题及返回入口、层级；锚点落点不被遮住，重复选择当前章节仍符合定位规则；滚动容器、返回位置正确；表格保留适用的内部滚动、固定列及分页，悬浮控件不遮挡金额、正文阅读或主要操作 |
| 搜索、筛选与视图 | 默认值、组合条件、清除、URL/缓存优先级、卡片/列表切换；无结果和失败恢复 |
| 输入与参数 | 键盘/点击一致，参数打开/关闭、重置、模型/类型切换；控件位置不因内容变化意外抖动 |
| 登录或权限 | 未登录填写、各登录方式成功续接、取消/失败、无效回跳；不串账号、不重复执行付费操作 |
| 提交与异步结果 | 校验、请求中防重复、成功/失败重试、取消；刷新查询已有任务而非重复提交，仅在适用时验证 |
| 操作反馈 | 对照项目反馈规范真实触发受影响操作；等待成功／可复现失败反馈出现，检查承载组件、内容、位置、层级、关闭／自动消失及重复提示。对比操作前后布局，轻反馈不增加常驻说明或挤动页面；持久状态和可恢复错误不只靠短暂气泡。记录未触发的分支，不能凭初始截图或构建判定通过 |
| 数据展示 | 对照当前规则核对共有字段，再逐一检查受影响状态应增加、隐藏的信息与操作；区分不适用、真实缺失和样例不完整。核对来源、单位、空值与0、失效对象及长内容，金额／币种／单位／条件保持关联且窄屏可读；不以合成结果证明真实服务能力 |
| 文案与补充提示 | 按列表、详情等承载位置核对同类提示是否一致，删除重复和防御性说明后，页面对象与下一步仍清楚；必要标签、费用、权限和操作后果可见，补充信息支持键盘与触屏 |
| 公开内容与 SEO | 页面主题、标题层级、有用正文、有效链接、当前页面元信息及手机等价内容；按项目契约检查原始 HTML 与折叠内容，区分预览索引规则和正式技术验收 |
| 删除或迁移入口 | 受影响导航/页脚/结果页、旧地址及返回；不留死链，不恢复延期功能 |
| 交付环境 | 开发预览、静态产物、发布页分别标明；深链刷新、资源加载、模拟接口和关键流程在目标环境可用 |

浏览器检查应保留足够定位证据：页面/路径、主题或视口、操作和结果；优先更新现有验证入口，不为每个按钮新建报告。失败先修复并复查受影响路径，不能用更多截图弥补缺少关键流程。

修改登录/支付原型时可以验证模拟流程，但真实授权、支付、发信和权限变更按工具与用户授权处理；测试不是扩张权限的理由。
