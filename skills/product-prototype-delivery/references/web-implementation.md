# Web 实现与兼容性

遇到新的交互机制、浏览器 API 或真实的可访问性、性能、兼容性疑点时，先定位目标浏览器、框架约束和现有组件。复用稳定组件；缺少合适方案时，从一个具体能力和实际失败场景查证。

- 表单和操作优先用原生标签、按钮和输入控件。用键盘走完提交、失败恢复和退出，确认焦点可见，提示可以被读取。
- 浮层、弹窗及动态更新先核对焦点进入与返回、关闭方式及读屏反馈。检查长文本、窄屏和实际滚动容器。
- 新 API 先查支持范围和降级方案，按目标浏览器验证。用可观察的行为或测量验证性能问题，保留检查的环境。
- 查具体实现可以用 [MDN Web Platform](https://developer.mozilla.org/en-US/docs/Web) 的说明和兼容性表。需要专项指南时可查 [Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance) 的相关主题。使用现有环境的检索能力即可，包内工作流和示例无需安装外部 CLI。
